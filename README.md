# Bunker Packs Editor

Редактор своих паков для [bunker-online.com](https://bunker-online.com).  

Программа редактирует только личные паки. Базовые и дополнительные паки сайта в неё не входят.

## Как развернуть у себя

Нужны Windows и [Node.js](https://nodejs.org/) 20 или новее. Вместе с Node ставится npm.

Скачай проект и открой его папку в терминале:

```powershell
cd путь\к\папке\проекта
npm install
```

Если Electron после установки не отсутсвует, докачай бинарники вручную:

```powershell
node node_modules/electron/install.js
node node_modules/esbuild/install.js
```

Запуск из исходников поднимает Vite и само приложение:

```powershell
npm run dev
```

Сайт интерфейса слушает `http://127.0.0.1:5174`. Команда `npm start` открывает только Electron и ждёт, что отклика от сайта, поэтому для разработки используй `npm run dev`.

Вход идёт в аккаунт bunker-online.com. Галочка «Запомнить» хранит логин на этом компьютере. Если входить не хочется, на том же экране есть «Автономный режим»: паки остаются локально и на сайт не уходят.

## Как собрать

Веб-часть без установщика:

```powershell
npm run build
```

Готовые файлы появятся в `dist`.

Приложение для Windows, установщик и портативная версия:

```powershell
npm run build:win
```

Сборка кладёт результат в `release`:

| Файл | Что это |
| --- | --- |
| `Bunker Packs Editor Setup 1.4.0.exe` | Установщик. Папку можно выбрать, ярлык попадает на рабочий стол и в меню Пуск |
| `Bunker Packs Editor 1.4.0.exe` | Портативная версия, без установки |
| `win-unpacked\` | Распакованное приложение, его можно запустить сразу |

Ярлык называется **Bunker Packs Editor**.

## О программе

После короткой проверки сессии открывается вход. Логин и пароль отправляются на сайт. «Автономный режим» пропускает аккаунт и оставляет только локальные файлы.

![Экран входа](<githubIMG/login.png>)

В главном меню после входа виден ваш ник и список своих паков. «Создать пак» Создает новый пак в профиле, «Открыть» берёт JSON с диска. У каждой строки есть «Редактировать» и «Удалить». «Обновить».

![Главное меню](<githubIMG/menu.png>)

Редактор хранит название, описание и все разделы пака: катаклизм, бункер, персонажа, инвентарь и спецвозможность. У профессии, пола, здоровья, хобби и телосложения есть справка с сайта. Готовый пак сохраняется в профиль. JSON можно скачать, загрузить обратно, очистить или почистить от повторов.

![Редактор пака](<githubIMG/editor%20menu.png>)

Без входа запускается «Автономный режим». Здесь можно так же создать пак или открыть уже существующий. Выгрузки в профиль нельзя: пак записывается только на компьютер. «Выйти» возвращает к экрану входа.

![Автономный режим](<githubIMG/no%20login%20menu.png>)
